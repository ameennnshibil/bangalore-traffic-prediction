# 🚦 Bangalore Traffic Prediction System

A machine learning-based web application that predicts traffic volume in Bangalore using traffic-related parameters such as average speed, travel time index, and road capacity utilization.

The application is built using Python, Streamlit, Pandas, and a trained machine learning model.

## 📌 Project Overview

Traffic congestion is a major problem in Bangalore. This project uses machine learning to estimate traffic volume based on selected road and traffic conditions.

The system provides a simple web interface where users can enter traffic details and receive:

- Predicted traffic volume
- Traffic status
- Low, Moderate, or High traffic classification

## ✨ Features

- 🚗 Traffic volume prediction
- 📊 Interactive Streamlit interface
- ⚡ Fast prediction using a trained ML model
- 📈 Traffic status classification
- 📁 Dataset-based machine learning model
- 🖥️ Simple and user-friendly interface
